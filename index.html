        Conectar a mi nodo

        1. Arranca tu nodo: bitcoind -regtest -daemon
        2. Descarga este proyecto y arranca el puente de solo lectura:
          BITCOIN_RPC_COOKIE=~/.bitcoin/regtest/.cookie npm run nodo
        3. Escribe la dirección del puente y conecta.

        Hecho por Alfredo Cruz a partir de su laboratorio con Bitcoin Core en regtest. Simplificado para aprender: no hay firmas ni scripts.
